## What Are Tokens?

LLMs do not process text exactly as individual words. Text is divided into smaller units called **tokens**.

For example:

```text
"Hello, how are you?"
```

is converted into tokens before being processed by the model.

The number of tokens is important because LLM APIs generally have limits and usage/costs associated with the number of tokens processed.

---

## Types of Tokens

### 1. Prompt Tokens

These are the tokens contained in the input sent to the model.

```python
usage.prompt_tokens
```

### 2. Completion Tokens

These are the tokens generated by the model in its response.

```python
usage.completion_tokens
```

### 3. Total Tokens

This represents the total number of tokens used for the request.

```python
usage.total_tokens
```

Conceptually:

```text
Total Tokens = Prompt Tokens + Completion Tokens
```

---

## Code Overview

The program sends multiple prompts to the LLM:

```python
prompt1 = "hi"
prompt2 = "what is time travel?"
prompt3 = "write a 1000 words essay on AI"

prompts = [prompt1, prompt2, prompt3]
```

A `for` loop is then used to send each prompt to the model:

```python
for prompt in prompts:
```

After receiving the response, token usage can be accessed using:

```python
usage = response.usage
```

The token information is then displayed:

```python
print(
    f"Prompt: {prompt} --> "
    f"prompt tokens: {usage.prompt_tokens} "
    f"completion tokens: {usage.completion_tokens} "
    f"total tokens: {usage.total_tokens}"
)
```

---

## Key Learning

I learned that:

- LLMs process text using tokens.
- Input text contributes to **prompt tokens**.
- Generated output contributes to **completion tokens**.
- Prompt and completion tokens together make up the **total token usage**.
- Token usage can be accessed from the API response.
- Longer prompts and responses generally use more tokens.
- Token usage is important when working with LLM limits and API costs.

---

## Important Observation

Different prompts can use different numbers of tokens.

For example:

```text
"Hi"
```

will generally require fewer tokens than:

```text
"Write a 1000-word essay explaining artificial intelligence."
```

This demonstrates why understanding token usage is important when building AI applications.

---

## Key Takeaway

Tokens are the basic units of text processed by an LLM. Understanding token usage is important for managing **context limits, API usage, and costs** when developing LLM-based applications.
